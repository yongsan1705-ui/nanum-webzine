# 웹진 「나눔, 그리고 나음」

센트럴서울안과 소식지 웹진 연습 프로젝트 (2024 Vol.06 오프라인판 원고 기반)

| 폴더 | 내용 |
| --- | --- |
| `nanum/` | 배포용 웹진 — 기사 HTML, 상담·구독 신청 페이지, 접수 API·관리자(DB) 페이지(PHP) |
| `build/` | 원고(`data.js`)와 HTML 생성 스크립트 — `cd build && node build.js` |
| `_preview/` | 서버 없이 보는 시연용 DB 화면 (배포하지 않음) |
| `_prototype/` | 이전 한 페이지 시제품 |

설치 방법은 [업체전달_설치안내.md](업체전달_설치안내.md)를 참고하세요.

- 테스트 단계에서는 실제 환자 정보를 입력하지 않습니다.
- 비밀번호·DB 접속정보·`config.php`의 실제 `secret` 값은 저장소에 올리지 않습니다.
